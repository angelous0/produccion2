✓ Decisiones cerradas (Ambission)

1.
Toda prenda devuelta entra al PT. No existe "merma" estándar. El sistema clasifica el resultado en OK · LQ Leve · LQ Grave, que conecta directo con la Distribución Esperada que ya tienes.
2.
Caso "no devuelto" (proveedor desaparece) es excepcional. Va como link secundario en el bottom sheet, no como contador. Queda registrado como pérdida interna.
3.
Precio facturado al proveedor es manual. En la pantalla "pasar a facturación" hay un input de precio unitario que el supervisor escribe. Sin descuentos automáticos, sin reglas.

Si validas, esto es lo que hago:

  1. 1. Cortes Calidad → versión web compacta (filas de una línea) + móvil queda igual.
  2. 2. Drawer "+ Fallado" → en web y móvil, añado el bloque azul de asignación cuando es servicio.
  3. 3. Tablero Fallados → versión móvil con tarjetas + web queda igual.
  4. 4. Bottom sheet "Recibir entrega" → 3 contadores (OK / LQ Leve / LQ Grave) + link "No devuelto".
  5. 5. Sprint facturación → input manual de precio unitario.
  6. 6. Pusheo a la rama produccion2 y tú despliegas en EasyPanel.
