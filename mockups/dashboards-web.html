📱 KPIs que viajan al móvil (vista resumida)

Una vez aprobados los dashboards web, llevamos al móvil solo los KPIs y alertas accionables, no las tablas grandes. En el Home móvil aparecería una nueva sección "📊 Tu día" con:

  • Card Hoy: Vencidos / Paralizados / Muestras +5d / Fallados pendientes (del Dashboard Operativo)
  • Card Bottleneck: qué taller está saturado (1-2 líneas)
  • Card Mes: prendas terminadas vs mes anterior + entrega a tiempo % (del Ejecutivo)
  • Card Costos: cuánto debes pagar y cuánto puedes cobrar (del Financiero)

Cada card tiene un botón "Ver detalle" que en mobile abre la pantalla con los datos resumidos y un botón "Abrir en web" para el dashboard completo.

⏭️ Plan de implementación sugerido

  1. Sprint 45 · Dashboard Throughput ⚡ (4 días). El que vos pediste recién. Endpoint nuevo único /throughput?desde=&hasta= + 1 pantalla web. Mi pick para arrancar porque responde "¿cuánto se hizo esta semana?" para todos los roles.
  2. Sprint 46 · Dashboard Operativo (1 semana). Diana lo abre cada mañana. Cuellos de botella, incidencias en vivo, producción del día. Datos ya existen.
  3. Sprint 47 · Dashboard Ejecutivo (1 semana). KPIs grandes, tendencia 6 meses, flujo por etapa, alertas críticas. 95% data ya existe.
  4. Sprint 48 · KPIs móviles (3 días). Card "Tu día" en el Home móvil con resumen de los 3 anteriores. Endpoint agregador único.
  5. Sprint 49 · Dashboard Talleres (1 semana). Requiere un endpoint agregador nuevo por persona. Ranking, calidad, pagos.
  6. Sprint 50 · Dashboard Financiero (1.5 semanas). El que más cambios pide en backend (campo "pagado" en movimientos, módulo de pagos formal).
  7. Sprint 51 · Dashboard Modelos (1 semana). El menos urgente. Útil para revisiones trimestrales.

Recomendación honesta: empezar por Throughput (rápido, alto impacto, respondes a tu pregunta directa), después Operativo y Ejecutivo en paralelo. El resto puede esperar 1-2 meses.

Para decidir antes de codear

  • ¿Por dónde empezamos? Mi voto: Operativo + Ejecutivo en paralelo, después móvil.
  • ¿Hay una vista que falta? Algunos que no incluí: Dashboard de stock/MP, Dashboard de cumplimiento (clientes), Dashboard de líneas de negocio. Decime si alguno de esos te resuena más.
  • ¿Los KPIs son los correctos? Si hay alguno que no aporta o falta otro, ahora es el momento de cambiarlo (antes de codear).
  • ¿Versión web única o por rol? ¿Todos ven todo o cada rol ve solo lo suyo?
